# UniCom 通信调试助手


UniCom 是一个面向 Windows 的轻量串口、TCP 与 UDP 调试助手。项目的目标很直接：做一个体积不太大、单文件、尽量不依赖各种运行库的实用工具，不需要安装，复制到目标电脑后即可使用，同时保留日常通信调试所需的易用性。

发布版为一个约 4 MB 的 32 位可执行文件，以 Windows XP SP3 和 Windows 7 为兼容基线，可在 32 位及 64 位 Windows 上运行。程序不依赖 .NET、VC++ 运行库或额外 DLL；USB 转串口设备仍需安装对应厂商的驱动。

> 本项目是使用 Codex 进行 vibe coding 开发的产品，代码、界面与文档均在人机协作中持续完善。

## 0.0.2 更新

- 在串口模式之外新增 TCP 客户端、TCP 服务端和 UDP 通信，支持 IPv4、IPv6、主机名及本地地址绑定
- TCP 客户端支持断线自动重连；TCP 服务端在客户端断开后继续监听新连接
- TCP/UDP 的本地或监听 IP 可从本机 IPv4 网卡地址中快捷选择，也可以手动输入 IPv6 地址
- IP 输入框支持 `host:port` 和 `[IPv6]:port`，按回车后自动拆分地址与端口，并兼容中文标点和多余空白
- TCP 服务端和 UDP 可在接收区标记数据来源，便于区分不同发送者
- 优化接收区滚动：停留在底部时自动跟随新数据，手动上滚或选择文本时保留当前位置
- 调整界面布局并更新应用图标

## 功能

### 串口连接

- 自动扫描串口，也可以手动输入 COM 端口
- 扩充丰富常用波特率预设（300 ~ 3000000）并支持自定义波特率
- 支持**打开串口后动态切换波特率**，无需重新打开串口
- 支持**自动波特率检测**功能，可一键扫描下位机数据流并匹配最佳波特率
- 支持 5/6/7/8 数据位、无/奇/偶/Mark/Space 校验和 1/1.5/2 停止位
- 支持无流控、RTS/CTS 硬件流控和 XON/XOFF 软件流控
- 支持 DTR、RTS 控制
- 串口意外断开后自动重连

### TCP 客户端连接

- 可通过连接类型下拉框选择 TCP 客户端模式
- 支持 IPv4、IPv6、主机名及 1-65535 端口
- 可选择是否指定本地 IP/端口；未指定时由系统自动分配
- 本地 IP 可从检测到的 IPv4 网卡地址中快捷选择，也可以手动输入
- TCP 连接中断或暂时不可用时可自动重连

### TCP 服务端连接

- 可指定本地监听 IP 和端口，支持 IPv4 与 IPv6
- 监听 IP 可从检测到的 IPv4 网卡地址中快捷选择，也可以手动输入
- 同一时刻接收一个客户端连接，并可与该客户端双向收发数据
- 客户端断开后保持监听，继续等待下一个客户端连接

### UDP 通信

- 必须指定对端 IP/端口，可选择是否指定本地 IP/端口；未指定时由系统自动分配
- 支持 IPv4、IPv6、主机名及 1-65535 端口；本地 IP 可使用 `0.0.0.0` 或 `::` 监听全部网卡
- 本地 IP 可从检测到的 IPv4 网卡地址中快捷选择，也可以手动输入
- 每次发送操作对应一个 UDP 数据报，并接收指定对端的数据报

### 数据收发

- 文本和 HEX 收发
- 收发编码可分别选择，支持 UTF-8、GBK、GB18030、Big5、ASCII、UTF-16LE/BE
- 文本发送支持转义字符
- 支持无行尾、CR、LF、CRLF
- 支持最低 20 ms 间隔的周期发送
- 接收区支持 HEX 显示、时间戳、自动滚动和自动换行；手动上滚或选择文本时不会被新数据拉回底部
- TCP 服务端和 UDP 模式支持按远端地址标记数据来源
- 实时显示 RX/TX 字节计数

### 调试与记录

- 内置终端模式，可处理常用终端控制序列并直接进行键盘交互
- 接收数据保存在内存缓存中，切换显示方式时可以重新渲染
- 接收内容可保存为文本，或保存为未经转换的原始二进制数据
- 自动记忆常用设置，配置保存在 `HKCU\Software\UniCom`

## 使用

运行 `build\unicom.exe` 即可，无需安装。也可以将该文件单独复制到其他 Windows 电脑上直接运行。窗口标题会显示当前版本号、Git 分支与提交短哈希，以及构建时间，便于确认正在使用的具体构建。

1. 在“连接”下拉框中选择串口、TCP 客户端、TCP 服务端或 UDP。
2. 串口模式选择端口并设置串口参数；TCP 客户端填写服务器地址和端口；TCP 服务端填写监听地址和端口；UDP 填写对端地址，并可选择指定本地地址。
3. 网络模式可在 IP 输入框中输入 `host:port` 或 `[IPv6]:port` 并按回车，让程序自动填写端口；本地或监听 IP 也可通过输入框右侧按钮选择。
4. 点击打开连接，然后在发送区输入文本或 HEX 数据。
5. 根据需要选择编码、行尾、周期发送、发送者标记或终端模式。

## 构建

项目固定使用 Go 1.10.8、Walk 2018-08-27 和 Win 2018-08-21。依赖已包含在仓库的 `vendor` 目录中，`build.sh` 会在未检测到 Go 1.10.8 时自动通过 `go install golang.org/dl/go1.10.8@latest` 下载并安装所需环境。

在 Git Bash 中执行：

```bash
./build.sh
```

跳过测试时可执行：

```bash
./build.sh --skip-tests
```

脚本会在 `build` 目录下创建临时 GOPATH，执行测试并生成 `build\unicom.exe`。

## 兼容性说明

- 自动重连会跟踪原 COM 端口号；如果设备重新插入后端口号发生变化，需要重新选择端口。
- GB18030 使用系统代码页 54936。极少数未安装该代码页的裁剪版 Windows XP 会提示不支持此编码。
